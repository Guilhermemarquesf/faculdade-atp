# Sistema de Eleição em C#

## Descrição

Este projeto foi desenvolvido em C# utilizando estruturas de repetição e condicionais para simular uma eleição entre dois candidatos.

O sistema:

* Valida a quantidade mínima de eleitores
* Recebe os votos dos eleitores
* Conta votos válidos, brancos e nulos
* Exibe o resultado da eleição
* Realiza uma nova eleição em caso de empate

---

# Funcionalidades

## Cadastro da eleição

O usuário informa:

* Quantidade de eleitores
* Número do candidato Teobaldo
* Número do candidato Astrogildo

---

## Registro de votos

Cada eleitor pode votar:

* No número do candidato Teobaldo
* No número do candidato Astrogildo
* `0` para voto em branco
* Qualquer outro número será considerado voto nulo

---

## Resultado da eleição

O sistema exibe:

* Quantidade de votos de cada candidato
* Quantidade de votos brancos
* Quantidade de votos nulos
* Candidato vencedor

---

## Regra de empate

Caso os candidatos tenham a mesma quantidade de votos:

* Uma nova eleição será iniciada automaticamente
