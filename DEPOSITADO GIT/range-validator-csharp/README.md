# Validador de Intervalo (0 a 100) em C# 📏

Este repositório contém um algoritmo desenvolvido em **C#** para verificar a presença de um número dentro de um intervalo específico (entre 0 e 100, inclusive).

## 🚀 Funcionalidades
* ✅ Entrada de valores inteiros ou decimais.
* ✅ Verificação lógica de limite inferior (0) e superior (100).
* ✅ Retorno imediato confirmando se o número "Está no intervalo" ou "Fora do intervalo".

## 🛠️ Tecnologias Utilizadas
* C#
* .NET 8.0
