# Operações Básicas: Soma e Subtração em C# ➕➖

Este repositório contém um algoritmo simples desenvolvido em **C#** para realizar cálculos de adição e subtração entre dois ou mais números inseridos pelo usuário.

## 🚀 Funcionalidades
* ✅ Entrada de dois valores numéricos (inteiros ou decimais).
* ✅ Cálculo da **Soma** ($a + b$).
* ✅ Cálculo da **Subtração** ($a - b$).
* ✅ Exibição clara dos resultados no console.

## 🛠️ Tecnologias Utilizadas
* C#
* .NET 8.0 (ou a versão que você estiver usando)
