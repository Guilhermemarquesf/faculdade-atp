# Verificador de Maioridade em C# 🔞

Este repositório contém um algoritmo desenvolvido em **C#** para validar a idade de um usuário e determinar se ele é maior de idade (18 anos ou mais). 

## 🚀 Funcionalidades
* ✅ Entrada da idade ou ano de nascimento via console.
* ✅ Cálculo de validação de maioridade.
* ✅ Mensagens personalizadas de "Acesso Permitido" ou "Acesso Negado".
* ✅ [Opcional: Uso de DateTime para pegar o ano atual automaticamente].

## 🛠️ Tecnologias Utilizadas
* C#
* .NET 8.0
