# Algoritmo Ímpar ou Par em C# 🔢

Este repositório contém um algoritmo desenvolvido em **C#** para identificar e classificar números inteiros. 
O objetivo deste projeto é exercitar a lógica de operadores matemáticos (módulo/resto da divisão) e estruturas condicionais `if/else`.

## 🚀 Funcionalidades
* ✅ Entrada de dados via console (números inteiros).
* ✅ Verificação automática se o número é Par ou Ímpar.
* ✅ Exibição de mensagens personalizadas com o resultado.
* ✅ [Opcional: Laço de repetição para múltiplas consultas].

## 🛠️ Tecnologias Utilizadas
* C#
* .NET 8.0 (ou a versão que você usa)
