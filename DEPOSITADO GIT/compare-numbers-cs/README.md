# Algoritmo de Comparação: Maior Número em C# 🔢

Este repositório contém um algoritmo desenvolvido em **C#** para comparar valores numéricos e identificar qual deles é o maior. 
O projeto foca no uso de estruturas condicionais encadeadas (`if`, `else if`, `else`) e lógica de comparação simples entre entradas de dados.

## 🚀 Funcionalidades
* ✅ Recebe múltiplos números via console.
* ✅ Compara os valores em tempo real.
* ✅ Identifica e exibe qual é o maior valor inserido.
* ✅ Tratamento básico para valores iguais.

## 🛠️ Tecnologias Utilizadas
* C#
* .NET 8.0 (ou a sua versão atual)
