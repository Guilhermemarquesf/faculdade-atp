# Verificador de Múltiplos de 5 em C# 🖐️

Este repositório contém um algoritmo desenvolvido em **C#** focado em lógica matemática e divisibilidade.

## 🚀 Funcionalidades
* ✅ Entrada de valores via terminal.
* ✅ Identificação de números múltiplos de 5.
* ✅ [Opcional: Listagem de múltiplos em um intervalo definido].
* ✅ Retorno visual claro para o usuário (Ex: "O número X é múltiplo de 5").

## 🛠️ Tecnologias Utilizadas
* C#
* .NET 8.0
