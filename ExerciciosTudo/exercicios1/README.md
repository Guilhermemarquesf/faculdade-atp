# Exercícios de Programação - PUC Minas

Este repositório contém a resolução dos exercícios e algoritmos desenvolvidos durante as aulas da **PUC**. O objetivo é documentar meu aprendizado e organizar as atividades práticas propostas pelos professores.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** C#
* **Ambiente:** .NET SDK
* **Editor:** Visual Studio Code / Visual Studio

## 📂 Estrutura do Repositório

Os arquivos estão organizados por temas ou listas de exercícios:

* `/Algoritmos-Basicos`: Exercícios introdutórios e lógica sequencial.
* `/Estruturas-Condicionais`: Práticas envolvendo `if/else`.
* `/Trabalhos-Pontuados`: Atividades específicas .
